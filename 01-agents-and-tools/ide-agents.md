# 💻 بررسی عمیق دستیارهای محیط توسعه و خط فرمان (IDEs, Extensions & CLI Agents)

در پارادایم وایب‌کدینگ، ویرایشگر یا محیط خط فرمان شما تنها یک واسط متنی نیست؛ بلکه یک **اتاق فرمان مهندسی** است که در آن ایجنت‌ها وظایف پیچیده‌ای مانند خواندن کدبیس، استخراج وابستگی‌ها، اجرای کامندهای شل، عیب‌یابی خطاهای بیلد و ثبت کامیت‌های گیت را بر عهده می‌گیرند.

این راهنما تحلیل فنی، مقایسه معماری، ترفندهای مصرف توکن و نقاط قوت و ضعف سه دسته اصلی از ابزارهای ایجنتیک را پوشش می‌دهد:
1. **ویرایشگرهای اختصاصی هوش مصنوعی (AI-First IDEs):** Cursor و Windsurf
2. **افزونه‌های متن‌باز و ابزارهای VS Code:** Cline & Roo Code و GitHub Copilot (Agent Mode)
3. **ایجنت‌های خودمختار خط فرمان (Terminal / CLI Agents):** Claude Code و Aider

---

## ۱. ویرایشگرهای بومی هوش مصنوعی (AI-First IDEs)

ویرایشگرهای این رده، فورک‌های بهینه‌سازی‌شده‌ای از VS Code هستند که قابلیت‌های ایجنتیک را در هسته ادیتور ادغام کرده‌اند تا ارتباط مدل با فایل‌ها بدون تاخیر باشد.

---

<a id="cursor"></a>
### ۱.۱. کرسر (Cursor) - استاندارد صنعت و پلتفرم کامل وایب‌کدینگ

Cursor در سال‌های اخیر مرزهای کدنویسی تعاملی را جابجا کرده است. این ابزار به جای اکتفا به یک پنجره گفتگوی ساده، مفهوم ویرایش چندفایلی یکپارچه و ایجنتیک را به استاندارد صنعت تبدیل نمود.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           معماری داخلی Cursor                           │
├────────────────────────────────┬────────────────────────────────────────┤
│     Composer / Agent Mode      │       Codebase Indexing Engine         │
│  • ویرایش خودکار فایل‌ها       │  • پارس ساختار با Tree-sitter          │
│  • اجرای مستقل دستورات ترمینال │  • امبدینگ برداری و جستجوی معنایی      │
│  • تشخیص و اصلاح لوپ‌های خطا   │  • ادغام تاریخچه گیت و داک‌ها          │
├────────────────────────────────┴────────────────────────────────────────┤
│                 لایه‌های هدایت‌کننده: Rules و Context                    │
│   • `.cursorrules` / `.cursor/rules/*.mdc`                             │
│   • کلیدهای ارجاع محتوا: `@Files`, `@Folders`, `@Docs`, `@Web`, `@Git`   │
└─────────────────────────────────────────────────────────────────────────┘
```

#### قابلیت‌های کلیدی و کاربرد فنی:
* **حالت ایجنتیک و کامپوزر (Composer / Agent Mode):**  
  با فشردن کلید میانبر `Ctrl + I` (یا کلید اختصاصی Composer)، مدل به یک معمار تمام‌عیار تبدیل می‌شود. در حالت **Agent Mode**، کرسر طرح اولیه کار را مشخص می‌کند، فایل‌های مورد نیاز را می‌سازد، ویرایش‌های موازی روی چندین فایل را به صورت Diff تفکیک‌شده نمایش می‌دهد و دستورات ترمینال (مانند نصب پکیج‌ها یا اجرای تست‌ها) را مستقیماً اجرا می‌کند.
* **نمادهای کانتکست (`@` Context Symbols):**  
  برای جلوگیری از ارسال کل پروژه و هدررفت توکن‌ها، کرسر از ارجاعات هدفمند پشتیبانی می‌کند:
  * `@Files` و `@Folders`: تزریق دقیق یک فایل یا یک پوشه به کانتکست پرامپت.
  * `@Codebase`: جستجوی برداری و معنایی در کل ریپازیتوری برای پیدا کردن توابع مرتبط بدون نیاز به دانستن نام فایل.
  * `@Docs`: خواندن آنلاین مستندات رسمی فریم‌ورک‌ها (مثلاً مستندات رسمی Next.js یا Tailwind).
  * `@Web`: جستجوی بلادرنگ در وب برای رفع خطاهای جدید.
  * `@Git`: ارجاع به آخرین تغییرات، لاگ‌ها و شاخه‌ها.
* **سیستم قوانین پروژه (`.cursorrules` و `.cursor/rules/*.mdc`):**  
  با قرار دادن این فایل‌ها در ریشه پروژه، سلیقه معماری، چارچوب RTL و استانداردهای کدنویسی پروژه را تعریف می‌کنید. سیستم جدید `.cursor/rules/` به شما اجازه می‌دهد قوانین را به صورت ماژولار و وابسته به مسیر فایل‌ها (Glob Patterns) پیکربندی کنید (برای نمونه‌های آماده، پوشه [`03-rules`](../03-rules) را ببینید).
* **حالت حریم خصوصی (Privacy Mode):**  
  در مسیر `Settings -> General -> Privacy Mode`، با فعال‌سازی این گزینه، کدهای شما در سرورهای کرسر ذخیره نشده و هرگز برای آموزش مدل‌ها استفاده نمی‌شوند (الزامی برای پروژه‌های تجاری و سازمانی).

#### راهنمای مصرف بهینه سهمیه Fast Requests (جلوگیری از اتمام سهمیه پرو):
اکانت‌های Cursor Pro معمولاً ۵۰۰ درخواست سریع (Fast Requests) در ماه دارند. برای جلوگیری از سوختن سریع این سهمیه:
1. **استفاده از مدل مناسب برای تسک مناسب:** برای کامنت‌گذاری، نوشتن تایپ‌ها یا اصلاحات تک‌خطی از مدل‌های سبک‌تر مانند `Claude 3.5 Haiku` یا `GPT-4o-mini` استفاده کنید و `Claude 3.5 Sonnet` / `Claude 3.7` را برای کارهای معماری و چندفایلی نگه دارید.
2. **پرهیز از `@Codebase` غیرضروری:** زمانی که می‌دانید کدام فایل نیاز به تغییر دارد، مستقیماً از `@filename` استفاده کنید. اسکن کل کدبیس حجم زیادی از پنجره کانتکست را پر می‌کند.
3. **ریست کردن دوره‌ای سشن چت:** چت‌های طولانی در Composer باعث ارسال مجدد کل تاریخچه در هر درخواست می‌شوند. پس از پایان هر تسک منطقی، با کلید `Ctrl + N` چت جدید باز کنید.

#### چه زمانی استفاده کنیم؟
* زمانی که به دنبال پخته‌ترین، پایدارترین و مدرن‌ترین تجربه توسعه فول‌استک چندفایلی در قالب یک IDE گرافیکی هستید.
* پروژه‌های تجاری تیمی که به فایل‌های استاندارد `.cursorrules` برای هدایت خروجی هوش مصنوعی وابسته‌اند.

#### چه زمانی استفاده نکنیم؟
* سیستم‌هایی با سخت‌افزار بسیار ضعیف یا رم کمتر از ۸ گیگابایت (کرسر به دلیل فرآیندهای الکترون و ایندکسینگ معنایی نیازمند منابع پردازشی کافی است).
* توسعه‌دهندگانی که تمایلی به پرداخت ماهانه ۲۰ دلار اشتراک ندارند و به دنبال راه‌حل‌های کاملاً رایگان بدون تاریخ انقضا هستند.

<a id="windsurf"></a>
### ۱.۲. ویندسرف (Windsurf by Codeium) - جریان کاری مبتنی بر Flows

ویندسرف ساخته شرکت Codeium است که فلسفه متفاوتی را دنبال می‌کند: همکاری بلادرنگ توسعه‌دهنده و مدل بدون شکسته‌شدن جریان تمرکز ذهنی (Flow State).

#### ویژگی‌های شاخص:
* **موتور Cascade:** هسته عامل ویندسرف است. کسکید دارای دو حالت عملیاتی است:
  * **Chat Mode:** بررسی، تحلیل، معماری و پاسخ به سوالات مفهومی بدون اعمال تغییر روی دیسک.
  * **Write Mode:** ورود به کدهای پروژه، ساخت فایل‌ها، بازنویسی توابع و اعمال اتوماتیک تغییرات.
* **شناخت عمیق و پیوسته کانتکست (Deep Codebase Awareness):**  
  بر خلاف کرسر که بر تگ کردن دستی فایل‌ها توسط کاربر با علامت `@` تکیه دارد، ویندسرف تاریخچه تب‌های باز اخیر شما، دستورات اخیر ترمینال و فایل‌های وابسته را به طور خودکار تحلیل می‌کند.
* **مقایسه عملکرد با Cursor در پروژه‌های بزرگ (Large Codebases):**
  * **ایندکسینگ:** ایندکسینگ ویندسرف بر پایگاه‌های کد غول‌پیکر (Monorepo) فشار حافظه‌ای (RAM) کمتری به سیستم محلی وارد می‌کند.
  * **پیوستگی تراکنش‌ها:** در زمان کدنویسی، تغییرات ویندسرف در تعامل پیوسته با کاربر اعمال می‌شود.
  * **قیمت‌گذاری:** اشتراک Pro ماهانه ۲۰ دلار است (مشابه Cursor)، اما پلن رایگان اولیه ویندسرف شامل تکمیل کد (Autocomplete) و ویرایش درون‌خطی نامحدود با سهمیه مصرف دوره‌ای در Cascade است.

#### چه زمانی استفاده کنیم؟
* در پروژه‌های بزرگ و مونو‌ریپوهایی که تگ کردن مکرر دستی فایل‌ها تمرکز ذهنی برنامه‌نویس را از بین می‌برد.
* توسعه‌دهندگانی که خواهان استفاده از قابلیت Autocomplete رایگان و نامحدود به همراه سهمیه‌های پایه ایجنتیک هستند.

#### چه زمانی استفاده نکنیم؟
* اگر پروژه شما به شدت وابسته به سیستم‌های پیشرفته قوانین چندفایلی ماژولار گیت‌محور (نظیر `.cursor/rules/*.mdc`) است.
* اگر در سازمانی کار می‌کنید که نیاز به اتصال کلیدهای API اختصاصی شرکتی (BYOK) در پلن‌های معمولی دارید.

## ۲. افزونه‌های متن‌باز VS Code و گزینه‌های درون‌برنامه‌ای

اگر نمی‌خواهید از یک فورک متفرقه استفاده کنید و ترجیح می‌دهید روی همان **VS Code رسمی** با آزادی ۱۰۰٪ در انتخاب ارائه‌دهنده یا در چارچوب اکوسیستم رسمی مایکروسافت کار کنید، این بخش متعلق به شماست.

---

<a id="cline-roo-code"></a>
### ۲.۱. کلاین و رو کد (Cline & Roo Code) - پادشاهان استک رایگان و BYOK

**Cline** (و نسخه ارتقایافته و بسیار محبوب کامیونیتی آن، **Roo Code**) استاندارد طلایی افزونه‌های خودمختار متن‌باز محسوب می‌شوند.

```
┌────────────────────────────────────────────────────────────────────────┐
│                        معماری افزونه Roo Code                          │
├────────────────────────────────────────────────────────────────────────┤
│                        سیکل تصمیم‌گیری ایجنت                           │
│     [پرامپت کاربر] ──> [بررسی ابزارها] ──> [اجرای دستور] ──> [تحلیل نتیجه]   │
│                               ▲                             │          │
│                               └────── بازگشت به لوپ ────────┘          │
├────────────────────────────────────────────────────────────────────────┤
│                           ابزارهای در دسترس                            │
│  • `read_file` / `write_to_file` / `apply_diff`                         │
│  • `execute_command` (ترمینال مستقل و کنترل خطاها)                     │
│  • `browser_action` (کنترل خودکار مروگر با Puppeteer)                  │
│  • `use_mcp_tool` (پروتکل سرورهای زمینه مدل - MCP)                     │
└────────────────────────────────────────────────────────────────────────┘
```

#### نحوه عملکرد داخلی:
Roo Code یک ایجنت ابزارمحور (ReAct Framework) است. مدل در هر چرخه فکر می‌کند، تصمیم می‌گیرد که آیا نیاز به دیدن یک فایل دارد یا اجرای یک کامند، سپس فراخوانی ابزار (Tool Call) مربوطه را ارسال می‌کند و پس از خواندن خروجی، گام بعدی را برمی‌دارد.

#### قابلیت‌های پیشرفته:
1. **اجرای خودمختار دستورات شل (Autonomous Terminal Execution):**  
   ایجنت می‌تواند دستورات پکیج منیجر (`npm run dev`، `cargo build`، `pytest`) را اجرا کند، لاگ‌های خطا را از ترمینال بخواند و تا سبز شدن تست‌ها به صورت مستقل کد را تغییر دهد (دارای امکان تأیید دستی تک‌به‌تک یا حالت Auto-approve با تعیین سقف هزینه و ریسک).
2. **استفاده از مرورگر (Browser Use / Puppeteer):**  
   اگر قابلیت مرورگر را فعال کنید، Roo Code یک نسخه سبک Chromium باز می‌کند، روی دکمه‌های سایت کلیک می‌نماید، کنسول لاگ‌های فرانت‌اند را می‌خواند و در صورت مشاهده خطای بصری، اسکرین‌شات گرفته و آن را خودکار رفع می‌کند.
3. **حالت‌های اختصاصی قابل شخصی‌سازی (Custom Modes):**  
   می‌توانید نقش‌های اختصاصی برای افزونه بسازید:
   * **Architect Mode:** فقط اجازه خواندن فایل‌ها، تحلیل ساختار و طراحی بدون دستکاری کدها.
   * **Code Mode:** نوشتن و ریفکتور کدهای پروژه.
   * **Ask Mode:** پاسخ به سوالات بدون اجازه اجرای دستور در ترمینال.
   * **Test Engineer Mode:** نقش اختصاصی که فقط حق ایجاد و اجرای تست‌های واحد (Unit Tests) را دارد.

#### چرا Cline / Roo Code بهترین انتخاب برای توسعه‌دهندگان ایرانی است؟
* **آزادی مطلق BYOK (Bring Your Own Key):** هیچ شرکتی نمی‌تواند دسترسی شما را به خاطر آی‌پی ایران مسدود کند. شما می‌توانید افزونه را به هر ارائه‌دهنده‌ای متصل کنید:
  * کلید رایگان **Google Gemini 2.5 Flash** در سرویس Google AI Studio (سهمیه فوق‌العاده بالا بدون نیاز به کارت بانکی).
  * کلیدهای ارزان‌قیمت **OpenRouter** (دسترسی به DeepSeek V3، Claude 3.5 Sonnet، Llama 3 بدون محدودیت IP).
  * ارائه‌دهنده فوق‌سریع **Groq**.
  * مدل‌های لوکال ۱۰۰٪ آفلاین و رایگان از طریق **Ollama** روی سیستم خودتان.
* **شفافیت کامل هزینه‌ها:** در هر لحظه تعداد توکن‌های ورودی، خروجی و سنت‌های مصرف‌شده در پایین پنجره نمایش داده می‌شود.

#### چه زمانی استفاده کنیم؟
* کاربرانی که به دنبال هزینه صفر یا هزینه به اندازه مصرف دقیق (Pay-as-you-go) هستند.
* توسعه‌دهندگانی که می‌خواهند از مدل‌های متنوع (Gemini, DeepSeek, Claude) در یک محیط استفاده کنند.
* نیاز به اتوماسیون تست مرورگر با Puppeteer بدون نوشتن کدهای تست دستی.

#### چه زمانی استفاده نکنیم؟
* اگر از پیکربندی دستی کلیدهای API، تنظیم دستی پارامترهای مدل و مدیریت پرامپت‌ها خسته می‌شوید و خواهان یک محیط آماده با یک کلیک هستید.

<a id="copilot-agent"></a>
### ۲.۲. گیت‌هاب کوپایلوت ایجنت (GitHub Copilot Agent Mode)

مایکروسافت و گیت‌هاب قابلیت‌های Copilot را از تکمیل کد ساده و پنجره چت فراتر برده و قابلیت **Agent Mode** را در بخش Copilot Edits در VS Code رسمی تعبیه کرده‌اند.

#### قابلیت‌های فنی:
* **ویرایش خودمختار چندفایلی (Autonomous Multi-File Editing):** ایجنت کوپایلوت می‌تواند فایل‌های وابسته به یک تغییر را شناسایی کند، تغییرات را به صورت موازی اعمال کرده و سپس از کاربر تایید بگیرد.
* **لوپ خطایابی و تست:** با دسترسی به شل داخلی، تست‌های پروژه را اجرا کرده و در صورت بروز خطا، راه‌حل اصلاحی را تا پاس شدن تست‌ها اعمال می‌کند.
* **پشتیبانی از پروتکل MCP:** قابلیت اتصال ابزارهای شخص ثالث از طریق استاندارد Model Context Protocol را دارد.
* **پلن قیمت‌گذاری و آموزش:** هزینه اشتراک فردی ۱۰ دلار در ماه است (ارزان‌تر از اکانت‌های ۲۰ دلاری کرسر یا ویندسرف)، و برای دانشجویان و اساتید تاییدشده در برنامه **GitHub Education** و نگه‌دارندگان پروژه‌های متن‌باز معروف ۱۰۰٪ رایگان است.

#### چه زمانی استفاده کنیم؟
* دانشجویان و دانشگاهیانی که اشتراک رایگان GitHub Student Developer Pack دارند.
* محیط‌های تجاری و شرکتی تحت لایسنس‌های شرکتی مایکروسافت (GitHub Enterprise) که استفاده از ابزارهای شخص ثالث متفرقه در آن‌ها ممنوع است.
* پروژه‌های دات‌نت (.NET/C#)، جاوا و تایپ‌اسکریپت سازمانی.

#### چه زمانی استفاده نکنیم؟
* اگر خواهان آزادی اتصال مدل‌های سفارشی خارج از اکوسیستم مایکروسافت/اوپن‌ای‌آی (BYOK) هستید.
* پروژه‌هایی که نیازمند دور زدن سخت‌گیرانه تحریم‌ها با کلیدهای API دلخواه بدون اتکا به شبکه گیت‌هاب هستند.

## ۳. ایجنت‌های خودمختار خط فرمان (Terminal / CLI Agents)

برای مهندسان ارشد، متخصصان دواپس و علاقه‌مندان به محیط‌های مینیمال، ایجنت‌های خط فرمان تجربه‌ای خالص و پرسرعت بدون سربار واسط‌های سنگین گرافیکی فراهم می‌آورند.

<a id="claude-code"></a>
### ۳.۱. کلود کد (Claude Code) - پیشرفته‌ترین ایجنت ترمینالی Anthropic

Claude Code که توسط کمپانی Anthropic توسعه یافته، یک ابزار تعاملی خط فرمان است که تسلط فوق‌العاده‌ای بر ریپازیتوری‌های محلی گیت و تغییرات ساختاری کد دارد.

```bash
# نصب جهانی کلود کد از طریق پکیج منیجر npm
npm install -g @anthropic-ai/claude-code

# ورود به پوشه پروژه گیت و اجرای ایجنت
cd my-project
claude
```

#### چرا کلود کد تا این حد متمایز است؟
* **ادغام مستقیم با Git:** به طور خودکار لاگ تغییرات را رصد می‌کند، به ازای هر تسک کامیت‌های شفاف بر اساس شیوه نگارش Conventional Commits ثبت می‌کند و در صورت بروز خطا امکان بازگردانی آسان تغییرات با Git را فراهم می‌آورد.
* **لوپ‌های تصحیح خودکار تست (Test-Fix Loops):**  
  تنها کافی است پرامپت دهید: `Run npm test and fix any failing test in authentication module`. کلود کد دستور تست را اجرا کرده، خطای استک‌تریس را تحلیل می‌کند، فایل را ویرایش می‌نماید، مجدداً تست را اجرا می‌کند و تا سبز شدن کامل همه تست‌ها به کار ادامه می‌دهد.
* **ایده‌آل برای سشن‌های SSH و سرورهای ابری:**  
  بدون نیاز به باز کردن ادیتور یا واسط گرافیکی سنگین، مستقیماً روی سرور لینوکسی تست و پروداکشن باگ‌ها را پیدا و اصلاح می‌کند.

> [!WARNING]
> **هشدار تحریم برای کاربران ایرانی:** کلود کد مستقیماً با سرورهای Anthropic ارتباط برقرار می‌کند. کمپانی آنتروپیک سخت‌گیرانه‌ترین سیاست‌های مسدودسازی IP و شماره تماس را دارد. برای اجرای بدون دردسر این ابزار در ایران، تنظیم متغیرهای `HTTP_PROXY` و `HTTPS_PROXY` روی پورت HTTP پراکسی (مانند `127.0.0.1:20809`) الزامی است (راهنمای آن در سند [`bypass-sanctions-dns.md`](bypass-sanctions-dns.md) تشریح شده است). توجه داشته باشید که کلود کد از فرمت `socks5://` در این متغیرها به صورت پیش‌فرض پشتیبانی نمی‌کند.

#### چه زمانی استفاده کنیم؟
* بازنویسی‌های معماری بزرگ (Refactoring)، به‌روزرسانی نسخه‌های فریم‌ورک‌ها و مهاجرت کدهای قدیمی.
* کار روی سرورهای لینوکس، کانتینرهای داکر و اتصال از راه دور با SSH.
* توسعه به روش تست‌محور (TDD) با لوپ‌های بسته اجرای تست.

#### چه زمانی استفاده نکنیم؟
* اگر پراکسی پایدار با آی‌پی تمیز ندارید (ریسک بن شدن حساب آنتروپیک).
* اگر برای تایید تغییرات کدبیس، نیاز به مقایسه بصری و رنگی فایل‌ها (Diff Viewer) در کنار هم دارید.

### ۳.۲. اِیدر (Aider) - جفت برنامه‌نویسی همیشگی شما در ترمینال

Aider یکی از باقدمت‌ترین، پایدارترین و معتبرترین ابزارهای متن‌باز CLI در دنیای هوش مصنوعی است که از ابتدا با فلسفه **Pair Programming** ساخته شده است.

#### مشخصات و قابلیت‌های فنی:
* **پشتیبانی از هر مدلی (Multi-Model via LiteLLM):** Aider از مدل‌های OpenAI، Claude، DeepSeek، Gemini، Groq یا مدل‌های آفلاین Ollama پشتیبانی می‌کند.
* **نقشه‌برداری مخزن با Tree-sitter (Repository Map):** Aider کل پروژه شما را با درخت نحو انتزاعی پارس کرده و نقشه‌ای فشرده از تمام توابع، کلاس‌ها و امضاها می‌سازد تا مدل با کمترین مصرف توکن، درک درستی از وابستگی‌های پروژه داشته باشد.
* **الگوی دو مدلی معمار و کدنویس (`/architect` Mode):**  
  در این حالت، یک مدل استدلال‌گر قوی (مانند Claude 3.7 Sonnet یا o3-mini) برنامه معماری و نقشه کار را تعیین می‌کند و یک مدل ارزان و پرسرعت (مانند DeepSeek V3 یا Gemini Flash) کار تایپ و تولید کد را انجام می‌دهد؛ این کار هزینه‌های توکن را تا ۸۰٪ کاهش می‌دهد.
* **کامیت اتوماتیک و دستور تست (`/test`):** Aider با اتمام هر تسک کامیت استاندارد ثبت می‌کند و با دستور `/test npm test` فرآیند خطایابی را خودکار می‌سازد.

```bash
# اجرای Aider با کلید OpenRouter و انتخاب مدل اقتصادی DeepSeek V3
export OPENROUTER_API_KEY="sk-or-v1-..."
aider --model openrouter/deepseek/deepseek-chat
```

#### چه زمانی استفاده کنیم؟
* توسعه‌دهندگانی که می‌خواهند از ترمینال کد بزنند اما آزادی کامل در انتخاب مدل‌ها (BYOK) و حتی مدل‌های ۱۰۰٪ آفلاین Ollama می‌خواهند.
* پروژه‌هایی که کنترل نسخه‌ها و دقت کامیت‌های گیت در اولویت اول تیم قرار دارد.

#### چه زمانی استفاده نکنیم؟
* کاربران تازه‌کاری که با دستورات خط فرمان و ترمینال راحت نیستند و رابط گرافیکی را ترجیح می‌دهند.

## 🛠️ پیشنهاد تیم برای برنامه‌نویسان ایرانی بر اساس سبک کاری

1. **مسیر هزینه صفر (دانشجویان و تازه‌کارها):**  
   افزونه **Roo Code** را روی VS Code رسمی نصب کنید، یک کلید API رایگان از **Google AI Studio** برای مدل Gemini 2.5 Flash دریافت نمایید و از یک محیط ایجنتیک فول‌استک بدون هزینه لذت ببرید.
2. **مسیر بهره‌وری ماکزیمم تجاری (تیم‌های حرفه‌ای و فریلنسرها):**  
   از **Cursor Pro** به همراه فایل‌های اختصاصی `.cursorrules` استفاده کنید؛ برای کاهش هزینه‌ها، تسک‌های سبک را به Haiku یا mini واگذار کنید و برای حل باگ‌های شبکه، گزینه Disable HTTP/2 را فعال نمایید.
3. **مسیر مهندسی سیستم، دواپس و سرور:**  
   بر **Aider** یا **Claude Code** مسلط شوید. توانایی کار مستقیم با گیت و اجرای خودکار تست‌ها در ترمینال، سرعت توسعه شما را چند برابر می‌کند.
